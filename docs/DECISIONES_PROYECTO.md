# Decisiones del proyecto

1. La llave biológica no es la orden: es centro + caseta + lote + fecha de entrada.
2. La orden es el conector operativo para consumo, mortalidad y producción.
3. El stock de alimento pertenece al almacén global configurado.
4. El consumo por caseta se explica por orden, aunque físicamente salga del mismo almacén.
5. El ICA se evalúa semanalmente; movimientos y hechos operativos permanecen diarios.
6. Entradas, traspasos, ajustes y logística no forman parte del numerador del ICA.
7. Una anomalía es una señal de revisión, no una conclusión definitiva.
8. Los datos raw nunca se modifican.
9. El maestro de organización actual no se usa para penalizar órdenes históricas que ya no aparecen vigentes.
10. Los materiales alternos de producto principal se aceptan cuando están definidos en configuración y aparecen con la combinación operativa correspondiente.
11. Movimientos logísticos y ajustes se conservan como contexto; no modifican automáticamente el saldo biológico.
