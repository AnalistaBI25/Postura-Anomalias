# Diccionario resumido de datos procesados

El diccionario completo está en `docs/data_dictionary.md`.

## Tablas principales

- `05_ciclos_detectados.csv`: ciclos productivos detectados.
- `06_linea_diaria_ciclos.csv`: línea diaria con aves, mortalidad, consumo, producción, edad, estándares e ICA.
- `09_stock_alimento_diario_global.csv`: reconstrucción diaria del stock global de alimento.
- `10_features_y_scores_diarios.csv`: features, reglas, score ML, score final y severidad.
- `11_anomalias_consumo.csv`: filas priorizadas para revisión experta.
